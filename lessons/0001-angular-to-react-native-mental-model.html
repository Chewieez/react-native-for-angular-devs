Lesson 0001: Angular Lead → React Native & Expo Mental Model

Translating Angular architecture concepts to React Native primitives, hooks, & Expo debugging workflows

1. The Paradigm Shift

As an Angular Lead, you already master component architecture, state lifecycle, and dependency flow. React Native achieves the exact same architectural goals with a leaner, functional paradigm.

Angular Concept React Native & Expo Equivalent Key Paradigm Difference
HTML Template JSX (View, Text, Image) No browser div or span tags. Text MUST be wrapped in <Text>.
@Input() Props (props) Read-only attributes passed down from parent components.
@Output() EventEmitter Callback Props Child calls parent callback function passed via props (e.g., onPress={handlePress}).
Service (providedIn: 'root') React Context + Custom Hooks Global state shared via createContext() and useContext() hook.
BehaviorSubject / State useState Hook Functional state. Calling setState(val) schedules a component re-render.
Lifecycle Hooks useEffect Hook Replaces ngOnInit, ngOnChanges, and ngOnDestroy in a unified hook.

2. Fast & Easy Expo Debugging

Dev Menu (Simulator): Press Cmd + D on macOS Simulator or shake device to open Expo Developer Menu.
  • Open JS Debugger: Inspect console logs, network requests, and step-through breakpoints.
  • Toggle Element Inspector: Tap elements on device to see margins, padding, and layout metrics live.
  • Terminal Hotkeys: Press r in terminal to reload bundle, m to toggle menu.
