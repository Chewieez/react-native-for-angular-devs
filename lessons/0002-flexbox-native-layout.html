🏛️ Pillar 1: Core Paradigms, Native UI & Layout (Foundations)

Lesson 0002: Native Flexbox & Layout Masterclass

Translating CSS Flexbox & web box model to React Native Yoga engine, column defaults, and SafeAreaView

1. The 3 Fundamental Rules of Native Layout

  1. Default Direction is Column: On the web, flex-direction defaults to row. In React Native, every View defaults to flexDirection: 'column' (vertical stacking).
  2. Unitless Dimensions: Dimensions are specified as unitless density-independent pixels (dp). Writing width: 100 means 100dp (never write unit strings like 100px, 100rem, or 100% unless as a percentage string '100%').
  3. flex: 1 Expands to Fill Bounds: Unlike web CSS where flex: 1 means flex-grow: 1, in React Native flex: 1 instructs a component to stretch and fill all available space within its parent container.

2. Web CSS vs. React Native Flexbox

Concept Angular (Web CSS) React Native (Yoga Engine)
Flex Direction row (Horizontal flow default) column (Vertical stack default)
Cross-Axis Alignment align-items: stretch alignItems: 'stretch'
Main-Axis Alignment justify-content: flex-start justifyContent: 'flex-start'
Positioning Model position: static (default) position: 'relative' (no fixed or sticky)
Flex Shrink Default flex-shrink: 1 (Shrinks to fit container) flexShrink: 0 (Won't shrink below content size)

3. Code Example: Screen Layout with SafeAreaView & Cards

Note: SafeAreaView is imported from the community library react-native-safe-area-context (installed via npx expo install react-native-safe-area-context), which properly handles dynamic notches, status bars, and home indicator home bars across modern iOS and Android devices.

import React from 'react';
import { View, Text, StyleSheet, Platform, StatusBar } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

export function DashboardScreen() {
  return (
    <SafeAreaView style={styles.safeArea}>
      <StatusBar barStyle="dark-content" />
      
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Dashboard</Text>
        <View style={styles.badge}>
          <Text style={styles.badgeText}>PRO</Text>
        </View>
      </View>

      <View style={styles.cardContainer}>
        <View style={styles.card}>
          <Text style={styles.cardTitle}>Total Sales</Text>
          <Text style={styles.cardValue}>$24,500</Text>
        </View>

        <View style={styles.card}>
          <Text style={styles.cardTitle}>Active Users</Text>
          <Text style={styles.cardValue}>1,240</Text>
        </View>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  safeArea: {
    flex: 1, // Fills entire device screen
    backgroundColor: '#f8f9fa',
    paddingHorizontal: 16,
  },
  header: {
    flexDirection: 'row', // Horizontal alignment
    justifyContent: 'space-between',
    alignItems: 'center',
    paddingVertical: 16,
    borderBottomWidth: 1,
    borderBottomColor: '#e9ecef',
  },
  headerTitle: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#111111',
  },
  badge: {
    backgroundColor: '#007AFF',
    paddingVertical: 4,
    paddingHorizontal: 8,
    borderRadius: 12,
  },
  badgeText: {
    color: '#ffffff',
    fontSize: 12,
    fontWeight: 'bold',
  },
  cardContainer: {
    flexDirection: 'row',
    gap: 12, // Native gap property supported in modern RN
    marginTop: 20,
  },
  card: {
    flex: 1, // Each card expands equally to fill 50% width
    backgroundColor: '#ffffff',
    padding: 16,
    borderRadius: 12,
    ...Platform.select({
      ios: {
        shadowColor: '#000000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.1,
        shadowRadius: 4,
      },
      android: {
        elevation: 3, // Android native shadow elevation
      },
    }),
  },
  cardTitle: {
    fontSize: 14,
    color: '#6c757d',
    marginBottom: 6,
  },
  cardValue: {
    fontSize: 20,
    fontWeight: 'bold',
    color: '#212529',
  },
});

4. Platform-Specific Styling & File Conventions

Mobile platforms have distinct visual standards (iOS shadows vs. Android elevation, iOS notch insets vs. Android status bars):

  • Platform.OS: Evaluate code branches using Platform.OS === 'ios' or Platform.OS === 'android'.
  • Platform.select: Inline style selection via Platform.select({ ios: { ... }, android: { ... } }).
  • Platform Extensions: Create platform-specific files like Button.ios.tsx and Button.android.tsx. React Native automatically resolves the correct file for the target build.
