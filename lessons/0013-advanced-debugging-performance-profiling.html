Lesson 0013: Advanced Debugging & Performance Profiling

Translating Angular Change Detection, Zone.js, and DevTools profiling into React Native threading, React DevTools, and memoization

1. Angular Debugging & Profiling vs. React Native Toolkit

In Angular, performance optimization revolves around Zone.js change detection ticks, `ChangeDetectionStrategy.OnPush`, and Angular DevTools. In React Native, profiling focuses on the interaction between the JavaScript Thread and the Native UI Thread:

Concept Angular (Web) React Native (Mobile)
Profiling & Flamegraphs Angular DevTools Profiler React DevTools Profiler
Async Tracking Zone.js Microtasks JS Thread Event Loop & Metro
Off-Main-Thread Execution ngZone.runOutsideAngular() UI Thread Worklets (Reanimated)
List Identity Preservation trackBy: item.id keyExtractor={(item) => item.id}
Subtree Render Skipping ChangeDetectionStrategy.OnPush React.memo() + useCallback()

2. Mobile Thread Architecture vs. Browser Main Thread

Angular web applications run inside a single browser main thread (DOM + styles + JS). React Native architecture separates execution across two primary threads:

Concept Angular (Web) React Native (Mobile)
Application Logic Browser JS Engine / Main Thread (Blocks touch/fetch if busy) JavaScript Thread (Hermes engine)
Rendering & Gestures Browser Compositor & GPU Thread UI (Native) Thread (Maintains 60/120 FPS layout & gestures)

3. Code Comparison: Angular `OnPush` vs. React Native `React.memo`

Let's look at how both frameworks prevent unnecessary re-renders of list items (e.g. BeReal feed items):

Angular: OnPush Component with `trackBy`

// post-card.component.ts
@Component({
  selector: 'app-post-card',
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `
    <div class="card">
      <h3>{{ post.title }}</h3>
      <button (click)="liked.emit(post.id)">❤️ Like</button>
    </div>
  `
})
export class PostCardComponent {
  @Input() post!: Post;
  @Output() liked = new EventEmitter<string>();
}

// In parent template:
// <app-post-card *ngFor="let item of posts; trackBy: trackById" [post]="item" (liked)="handleLike($event)">

React Native: `React.memo` + `useCallback` + `keyExtractor`

// PostCard.tsx
import React, { memo } from 'react';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';

export const PostCard = memo(function PostCard({
  post,
  onLike,
}: {
  post: { id: string; title: string };
  onLike: (id: string) => void;
}) {
  return (
    <View style={styles.card}>
      <Text style={styles.title}>{post.title}</Text>
      <TouchableOpacity onPress={() => onLike(post.id)}>
        <Text>❤️ Like</Text>
      </TouchableOpacity>
    </View>
  );
});

// Parent FlatList with useCallback:
// const handleLike = useCallback((id: string) => { ... }, []);
// <FlatList data={posts} keyExtractor={(item) => item.id} renderItem={...} />

4. FlatList Virtualization Tuning for High-Density Feeds

Similar to Angular CDK Virtual Scrolling (cdk-virtual-scroll-viewport), React Native's FlatList virtualizes offscreen rows to conserve mobile RAM:

<FlatList
  data={posts}
  keyExtractor={(item) => item.id}
  renderItem={renderItem}
  initialNumToRender={5}       // Render only enough items to fill initial screen viewport
  maxToRenderPerBatch={5}      // Control batch size per scroll increment
  windowSize={5}               // Reduce offscreen buffer to save RAM on photo feeds
  removeClippedSubviews={true} // Unmount native views outside current viewport
/>

5. Key Insights for Angular Leads

  • Identify Reference Equality Bugs: In React, passing inline arrow functions (onPress={() => doSomething()}) or inline objects (style={{ margin: 10 }}) breaks React.memo because a new memory reference is created every render. Always wrap handlers with useCallback and styles in StyleSheet.create.
  • Expo Dev Menu (Cmd+D / Cmd+M): Toggle the Performance Monitor to see live JS FPS and UI FPS counters while scrolling feeds.
  • No Global Zone.js Overhead: React does not monkey-patch global browser APIs like Zone.js; component renders are strictly initiated by state setters (useState, useReducer, or Context value changes).
