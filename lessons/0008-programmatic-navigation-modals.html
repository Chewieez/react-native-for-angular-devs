🧭 Pillar 3: Navigation, Modals & Deep Linking

Lesson 0008: Programmatic Navigation & Modals

Translating Router.navigate(), dialog services, and route params to router.push(), sheet modals, and useLocalSearchParams

1. Angular Router Service vs. Expo `useRouter()` Hook

In Angular, you inject the Router service (private router: Router) to navigate programmatically. In Expo Router, you call the useRouter() hook inside any functional component:

Concept Angular (Web) React Native (Expo Router)
Push Screen onto Stack this.router.navigate(['/feed']) router.push('/feed') (Enables native back transition)
Replace Current Screen this.router.navigate(['/login'], { replaceUrl: true }) router.replace('/(auth)/login') (Disables back navigation)
Navigate Back this.location.back() router.back() (Pops top screen off stack)
Declarative Link <a [routerLink]="['/profile']"> <Link href="/profile">

2. Dynamic Route Parameters (useLocalSearchParams)

In Angular, parameters are retrieved via ActivatedRoute.snapshot.params. In Expo Router, params match dynamic bracket filenames (e.g. src/app/user/[id].tsx) and are extracted with useLocalSearchParams():

// File: src/app/user/[id].tsx
import { View, Text, StyleSheet } from 'react-native';
import { useLocalSearchParams, useRouter } from 'expo-router';

export default function UserProfileScreen() {
  // Extract route parameters cleanly with TypeScript types
  const { id } = useLocalSearchParams<{ id: string }>();
  const router = useRouter();

  return (
    <View style={styles.container}>
      <Text style={styles.text}>Viewing User Profile: {id}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  text: { fontSize: 18, fontWeight: 'bold' },
});

3. Native Modal Presentations

Unlike Angular web modals requiring custom overlay components, native iOS and Android provide bottom sheet / modal card transitions. In Expo Router, you declare a modal screen inside a `_layout.tsx` Stack:

// src/app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      
      {/* Modal Screen Configuration */}
      <Stack.Screen 
        name="create-post-modal" 
        options={{ 
          presentation: 'modal', 
          headerTitle: 'Create New Post' 
        }} 
      />
    </Stack>
  );
}
Closing a Modal Programmatically: Inside create-post-modal.tsx, simply call router.back() after saving data to dismiss the modal and slide it back down natively!

Android Hardware Back Button & Gestures: Expo Router automatically intercepts Android's hardware back button and iOS edge swipe gestures to execute router.back(). For conditional back intercepts (e.g. unsaved form prompts), check router.canGoBack() or attach a listener with React Native's BackHandler.
