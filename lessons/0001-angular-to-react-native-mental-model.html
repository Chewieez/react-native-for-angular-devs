Lesson 0001: Angular Lead → React Native & Expo Mental Model

Translating Angular architecture concepts to React Native primitives, JSX, & Expo debugging workflows

1. The Core Architectural Paradigm Shift

As a senior Angular engineer or team lead, you already understand component trees, state management, and separation of concerns. The shift to React Native and Expo requires mapping your existing knowledge to React's functional paradigm and mobile native layout engine.

Angular Architecture React Native & Expo Equivalent Deep Architectural Paradigm Difference
HTML Template + SCSS Functional JSX + StyleSheet.create No browser DOM (div, span, p). Components return native view nodes (View, Text, Image).
@Input() Decorator Component Props (props) Props are read-only, immutable JavaScript objects passed down top-to-bottom.
@Output() EventEmitter Callback Function Props Child components trigger parent actions by calling callback functions passed as props (e.g. onPress={handlePress}).
Service (providedIn: 'root') React Context + Custom Hooks Global dependency injection without a framework container; data flows via createContext() and useContext().
BehaviorSubject / Signals useState() Hook Setter calls (setState(val)) queue a batched re-render — they are requests, not immediate synchronous updates.
Lifecycle (ngOnInit, ngOnDestroy) useEffect() Hook Unified hook managing setup, dependency tracking, and cleanup returns.

2. Side-by-Side Code Comparison: User Profile Card

Angular Component (HTML + TypeScript)

// user-card.component.ts
@Component({
  selector: 'app-user-card',
  template: `
    <div class="card">
      <img [src]="avatarUrl" alt="User avatar" class="avatar" />
      <div class="info">
        <h3>{{ name }}</h3>
        <button (click)="selected.emit(name)">Select</button>
      </div>
    </div>
  `,
  styleUrls: ['./user-card.component.scss']
})
export class UserCardComponent {
  @Input() name: string = '';
  @Input() avatarUrl: string = '';
  @Output() selected = new EventEmitter<string>();
}

React Native & Expo Component (TSX + StyleSheet)

// UserCard.tsx
import { View, Text, Image, Pressable, StyleSheet } from 'react-native';

interface UserCardProps {
  name: string;
  avatarUrl: string;
  onSelect: (name: string) => void;
}

export function UserCard({ name, avatarUrl, onSelect }: UserCardProps) {
  return (
    <View style={styles.card}>
      <Image source={{ uri: avatarUrl }} style={styles.avatar} />
      <View style={styles.info}>
        <Text style={styles.nameText}>{name}</Text>
        <Pressable style={styles.button} onPress={() => onSelect(name)}>
          <Text style={styles.buttonText}>Select</Text>
        </Pressable>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    flexDirection: 'row', // Default in React Native is 'column'!
    alignItems: 'center',
    padding: 16,
    backgroundColor: '#ffffff',
    borderRadius: 12,
  },
  avatar: {
    width: 50,
    height: 50, // Remote images MUST have explicit width & height
    borderRadius: 25,
  },
  info: {
    marginLeft: 12,
    flex: 1,
  },
  nameText: {
    fontSize: 18,
    fontWeight: 'bold',
    color: '#111111',
  },
  button: {
    marginTop: 8,
    backgroundColor: '#007AFF',
    paddingVertical: 8,
    paddingHorizontal: 16,
    borderRadius: 6,
  },
  buttonText: {
    color: '#ffffff',
    fontWeight: '600',
  },
});

3. Critical Mental Model Rules for React Native

  1. No HTML Elements: Web tags like <div>, <span>, <button>, and <p> do not exist on iOS or Android. Using them will crash your mobile app.
  2. Text Wrapping Rule: Every visible text string MUST be enclosed within a <Text> component. Raw strings directly inside <View> throw a runtime exception.
  3. Flexbox Defaults to Column: Unlike web CSS where flex-direction defaults to row, React Native components stack vertically (column) by default.
  4. No CSS File Imports: Styling is written using JavaScript objects via StyleSheet.create(), compiled natively via Yoga layout engine.

4. Fast & Easy Expo Debugging Workflow

Expo provides powerful devtools out-of-the-box when running npx expo start:

Expo Developer Menu Shortcuts:
  • iOS Simulator: Press Cmd + D (or Cmd + R to reload JS bundle).
  • Android Emulator: Press Cmd + M (or press r twice in Metro terminal).
  • Physical Device: Shake the device to open the Dev Menu.
  • Open JS Debugger / Chrome DevTools: Press j in the Metro terminal to attach Chrome DevTools or inspect console logs and network requests.
  • Toggle Element Inspector: Select "Toggle Element Inspector" from the Dev Menu to inspect live element margins, padding, and layout dimensions on screen.
  • Metro Terminal Controls: Press r to reload, m to open dev menu, a to launch Android emulator, i to launch iOS simulator.
