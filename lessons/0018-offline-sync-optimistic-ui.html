1. Web Caching vs. Mobile Offline-First Expectations

In Angular web applications, users expect a loading spinner if their connection drops. On mobile devices, users expect instant feeds from disk, smooth scrolling in subway tunnels, and zero-latency button responses with automatic background synchronization:

Concept Angular / Web React Native Offline Architecture
Cache Engine HTTP Cache / RxJS shareReplay() TanStack Query + MMKV disk persistence
Instant Feedback Wait for API response before updating UI Optimistic Updates (update cache first, roll back on failure)
Network Transitions Manual navigator.onLine listeners @react-native-community/netinfo auto-retry queue

2. Optimistic UI Mutations with TanStack Query

When a user taps "Like" or submits a comment on a BeReal post, update the screen in 0ms and send the network request in the background:

import { useMutation, useQueryClient } from '@tanstack/react-query';
import { supabase } from '../lib/supabase/client';

export function useLikePost() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: async ({ postId, userId }: { postId: string; userId: string }) => {
      const { error } = await supabase
        .from('likes')
        .insert([{ post_id: postId, user_id: userId }]);
      if (error) throw error;
    },

    // 1. When mutation is triggered:
    onMutate: async ({ postId }) => {
      // Cancel outgoing refetches so they don't overwrite optimistic update
      await queryClient.cancelQueries({ queryKey: ['posts'] });

      // Snapshot previous feed state for rollback
      const previousPosts = queryClient.getQueryData(['posts']);

      // Optimistically update the cache immediately!
      queryClient.setQueryData(['posts'], (old: any[] = []) =>
        old.map((post) =>
          post.id === postId
            ? { ...post, isLiked: true, likesCount: post.likesCount + 1 }
            : post
        )
      );

      return { previousPosts };
    },

    // 2. If the backend fails (e.g. timeout / offline error):
    onError: (err, variables, context) => {
      if (context?.previousPosts) {
        // Roll back to previous state seamlessly
        queryClient.setQueryData(['posts'], context.previousPosts);
      }
    },

    // 3. Always refetch after error or success to synchronize with server:
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
  });
}

3. Fast Disk Persistence with MMKV

Persist your query cache to lightning-fast local storage so the feed renders on app launch without waiting for network:

import { MMKV } from 'react-native-mmkv';
import { createSyncStoragePersister } from '@tanstack/query-sync-storage-persister';

export const storage = new MMKV();

// Sync storage persister adapter for TanStack Query
export const clientPersister = createSyncStoragePersister({
  storage: {
    setItem: (key, value) => storage.set(key, value),
    getItem: (key) => storage.getString(key) ?? null,
    removeItem: (key) => storage.delete(key),
  },
});

4. Key Insights for Angular Leads

  • Zero Latency Feel: Optimistic updates make mobile applications feel 10x faster because the UI never waits on HTTP round-trips for user actions.
  • Network Detection: Use NetInfo.addEventListener to pause outgoing mutations and auto-retry them as soon as LTE/Wi-Fi is re-established.
