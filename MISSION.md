# Mission: React Native, Expo & Mobile Development Mastery

## Why
Transition strong Angular Lead expertise into production-ready React Native & Expo cross-platform mobile development skills to broaden career opportunities and build full-featured mobile apps starting with the BeReal clone project.

## Success looks like
- Confidently architecting React Native apps with Expo Router, JSX, and Hooks (`useState`, `useEffect`, `useContext`).
- Translating Angular concepts (Services, Dependency Injection, RxJS, Inputs/Outputs) to React patterns (Context, Custom Hooks, Props, State).
- Using essential Expo & React Native debugging tools (Expo Dev Menu, React DevTools, Metro logs, console debugging) effortlessly.
- Completing and extending mobile projects with clean React Native patterns and backend integrations (Supabase/Firebase).

## Constraints
- Hands-on learning alongside building real projects.
- Leverage senior front-end (Angular) background to accelerate architectural learning while bridging React-specific paradigm differences.

## Out of scope
- Deep native Swift/Kotlin module writing (staying focused on Expo managed workflow & JavaScript/TypeScript layer).
