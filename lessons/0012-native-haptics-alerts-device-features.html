Lesson 0012: Native Haptics, Alerts & Device Features

Platform-specific code (Platform.OS / Platform.select), native tactile feedback (expo-haptics), and system dialogs (Alert.alert)

1. Web Alerts & Modals vs. Mobile Native System Dialogs

In Angular web development, window.alert() is universally avoided because it freezes the browser tab, leading to custom HTML/CSS modal dialogs (Angular Material Dialog, SweetAlert). In React Native, Alert.alert() triggers asynchronous native system dialogs (UIAlertController on iOS, AlertDialog on Android):

Concept Angular (Web) React Native (Mobile)
Alert Dialog Custom HTML Modal or MatDialog Alert.alert('Title', 'Message', buttons) (Native OS dialog)
Tactile Feedback navigator.vibrate() (poor web support) expo-haptics (Taptic Engine / Haptic Motors)
Platform Logic User-Agent sniffing (fragile) Platform.OS / Platform.select() (First-class branching)

2. Native Alert Dialogs (`Alert.alert`)

Native alerts take button definitions with callback handlers (including destructive red styling on iOS):

import { Alert } from 'react-native';

export function confirmDeletePost(postId: string, onDelete: (id: string) => void) {
  Alert.alert(
    'Delete Post',
    'Are you sure you want to permanently delete this BeReal post?',
    [
      {
        text: 'Cancel',
        style: 'cancel', // iOS standard gray cancel button
      },
      {
        text: 'Delete',
        style: 'destructive', // iOS red text
        onPress: () => onDelete(postId),
      },
    ],
    { cancelable: true } // Android tap-outside-to-dismiss behavior
  );
}

3. Adding Tactile Feedback with expo-haptics

Tactile haptic feedback is one of the clearest differentiators between a web wrapper and a true native mobile app:

import * as Haptics from 'expo-haptics';

// 1. Button Press Impact
export const triggerButtonHaptic = () => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
};

// 2. Heavy Action (e.g. Taking photo / deleting item)
export const triggerHeavyImpact = () => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy);
};

// 3. Success / Failure Notifications
export const triggerSuccessHaptic = () => {
  Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
};

export const triggerErrorHaptic = () => {
  Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error);
};

// 4. Picker Wheel / Scroll Selection
export const triggerSelectionHaptic = () => {
  Haptics.selectionAsync();
};

4. Platform-Specific Code Branching

When iOS and Android require different layout values, shadows, or components, use Platform.select or file extension branching:

import { Platform, StyleSheet, View } from 'react-native';

const styles = StyleSheet.create({
  card: {
    backgroundColor: '#fff',
    borderRadius: 12,
    padding: 16,
    // Cross-platform Shadow Pattern:
    ...Platform.select({
      ios: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.15,
        shadowRadius: 6,
      },
      android: {
        elevation: 4, // Android hardware elevation shadow
      },
      default: {
        borderWidth: 1,
        borderColor: '#ddd',
      },
    }),
  },
});

// Platform-specific file extensions:
// Button.ios.tsx   <- Loaded automatically on iOS
// Button.android.tsx <- Loaded automatically on Android
