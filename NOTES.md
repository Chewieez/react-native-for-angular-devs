# Teaching Notes & Preferences

- **Background**: Senior Front-End Dev / Team Lead with extensive Angular experience.
- **Learning Style**: Fast-paced conceptual translation (Angular -> React/RN), practical hands-on building, minimal fluff.
- **Key Analogies & Bridges**:
  - `@Input()` -> Component `props`
  - `@Output() EventEmitter` -> Callback functions passed as props (`onPress={handlePress}`)
  - Angular Services (`providedIn: 'root'`) -> React Context / Custom Hooks (`AuthContext`, `useAuth`)
  - RxJS / Signals -> `useState`, `useReducer`, or React state + `useEffect`
  - Template HTML & CSS -> JSX + `StyleSheet` / Flexbox
- **Debugging Focus**: Keep debugging tools straightforward, high-efficiency (Expo Dev Menu, React DevTools, Metro logs, `console.log`).
