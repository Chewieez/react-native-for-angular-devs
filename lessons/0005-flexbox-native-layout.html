Lesson 0005: Native Flexbox & Layout Masterclass

How React Native styling differs from CSS & Angular layout frameworks

1. The 3 Fundamental Rules of Native Layout

  1. Default Direction is Column: On the web, flex-direction defaults to row. In React Native, every View defaults to flexDirection: 'column'.
  2. No Unit Dimensions: Dimensions are unitless density-independent pixels (dp). Writing width: 100 means 100dp (not 100px or 100rem).
  3. flex: 1 Fills Available Space: Unlike web CSS where flex: 1 means flex-grow: 1, in React Native flex: 1 tells a component to expand to fill its parent container entirely.

2. Web CSS vs. React Native Flexbox

Property Web CSS Default React Native Default
flexDirection row column
alignItems stretch stretch
justifyContent flex-start flex-start
position static relative (Only relative or absolute exist)

3. Code Example & StyleSheet Utility

import { View, Text, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

export default function LayoutDemo() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.card}>
        <Text style={styles.title}>Card Title</Text>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1, // Fills entire device screen
    backgroundColor: '#fff',
    padding: 16,
  },
  card: {
    flexDirection: 'row', // Horizontally align children
    justifyContent: 'space-between',
    alignItems: 'center',
    padding: 20,
    backgroundColor: '#f5f5f5',
    borderRadius: 12,
  },
});
