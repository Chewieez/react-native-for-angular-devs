Lesson 0016: 60/120 FPS Native Gestures & Animations

UI-thread Worklets, declarative gestures (react-native-gesture-handler), and fluid physics springs (react-native-reanimated)

1. Angular Animations vs. React Native UI-Thread Worklets

In Angular web applications, animations rely on @angular/animations or CSS transitions running on the browser main thread. In React Native, running animations through the JavaScript thread can cause frame drops whenever heavy JS tasks run. react-native-reanimated solves this by executing JavaScript functions directly on the UI Thread (Worklets):

Concept Angular (Web) React Native (Mobile)
Execution Location Browser main thread Native UI Thread (Worklet C++ runtime)
Frame Rate Guarantee Drops when JS event loop is busy Guaranteed 60 / 120 Hz regardless of JS workload
State Drivers Angular state / CSS classes Shared Values (useSharedValue)
Physics & Easing CSS cubic-bezier curves Native physics springs (withSpring, withTiming)

2. Core Building Blocks of Reanimated 3

Reanimated uses Shared Values and Animated Styles:

import React from 'react';
import { View, StyleSheet, TouchableOpacity, Text } from 'react-native';
import Animated, { 
  useSharedValue, 
  useAnimatedStyle, 
  withSpring, 
  withTiming 
} from 'react-native-reanimated';

export function PulseHeartButton() {
  // 1. Shared Value (Stored on the UI thread)
  const scale = useSharedValue(1);

  // 2. Animated Style (Calculated at 60/120 FPS on the UI thread)
  const animatedStyle = useAnimatedStyle(() => {
    return {
      transform: [{ scale: scale.value }],
    };
  });

  const handlePress = () => {
    // 3. Spring physics animation
    scale.value = withSpring(1.4, { damping: 3, stiffness: 200 }, () => {
      scale.value = withSpring(1);
    });
  };

  return (
    <TouchableOpacity onPress={handlePress} activeOpacity={0.8}>
      <Animated.View style={[styles.heart, animatedStyle]}>
        <Text style={styles.heartText}>❤️</Text>
      </Animated.View>
    </TouchableOpacity>
  );
}

const styles = StyleSheet.create({
  heart: { width: 60, height: 60, justifyContent: 'center', alignItems: 'center' },
  heartText: { fontSize: 32 }
});

3. Interactive Gestures with GestureDetector

Combine GestureDetector from react-native-gesture-handler with Reanimated for gestures like Pinch-to-Zoom on photos (e.g. BeReal camera view):

import React from 'react';
import { StyleSheet } from 'react-native';
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

export function PinchableImage({ imageUri }: { imageUri: string }) {
  const scale = useSharedValue(1);
  const savedScale = useSharedValue(1);

  const pinchGesture = Gesture.Pinch()
    .onUpdate((e) => {
      scale.value = savedScale.value * e.scale;
    })
    .onEnd(() => {
      // Snap back to 1x scale when released
      scale.value = withSpring(1);
      savedScale.value = 1;
    });

  const imageAnimatedStyle = useAnimatedStyle(() => ({
    transform: [{ scale: scale.value }],
  }));

  return (
    <GestureDetector gesture={pinchGesture}>
      <Animated.Image
        source={{ uri: imageUri }}
        style={[styles.image, imageAnimatedStyle]}
      />
    </GestureDetector>
  );
}

const styles = StyleSheet.create({
  image: { width: 320, height: 400, borderRadius: 16 }
});

4. Key Insights for Angular Leads

  • Never Use useState for 60 FPS Animations: React useState causes full component re-renders across the bridge. Always use useSharedValue for animation state.
  • Worklets: Any JavaScript function marked with 'worklet'; is compiled to run directly on the UI thread without bridge overhead.
  • Layout Animations: Reanimated includes built-in layout transitions: <Animated.View entering={FadeInDown} exiting={FadeOutUp} /> for zero-boilerplate entrance/exit effects.
