Lesson 0003: What is a React Hook?

Demystifying hooks for Angular developers

1. The Simple Definition

A Hook is a JavaScript function (always prefixed with use, like useState or useAuth) that lets functional components "hook into" React features like state, lifecycle effects, and context.

2. Why Hooks Exist (The Angular Comparison)

Angular Components (Classes) React Components (Functions + Hooks)
Class instances preserve state in class properties (this.userName = 'Alex'). React components are plain functions that re-execute from top to bottom on every render. useState() tells React to preserve value across renders.
Lifecycle interfaces (ngOnInit, ngOnDestroy) are class methods. useEffect() is a hook function called inside the component to run side effects after rendering.
Services are injected in constructor (constructor(private auth: AuthService)). useContext(AuthContext) / useAuth() is a hook called inside the component to consume Context.

3. The 3 Rules of Hooks

  1. Only call hooks at the top level: Don't call hooks inside loops, conditions (if), or nested functions.
  2. Only call hooks from React function components or custom hooks: Don't call hooks from regular utility JS functions.
  3. Naming convention: Custom hooks MUST start with use (e.g. useAuth(), useUserProfile()).

4. Your useAuth() Custom Hook

In your AuthContext.tsx, you defined a custom hook:

export const useAuth = () => {
  const context = useContext(AuthContext);
  if (context === undefined) {
    throw new Error("useAuth must be used within AuthProvider");
  }
  return context;
};

Now, any component in your app simply calls const { user, signUp } = useAuth(); to access auth state and functions in one clean line!
