Lesson 0014: Production Builds & EAS Pipeline

Expo Application Services (EAS), app.json configuration, native app compilation, and Over-The-Air (OTA) live updates

1. Web Deployment vs. Mobile App Compilation

In Angular, production deployment involves bundling HTML/CSS/JS with Webpack/Vite and serving it from a CDN (S3, Cloudflare). In mobile development, native code (Swift/Objective-C/Kotlin/Java) must be compiled into cryptographic binary packages (.ipa for iOS, .aab for Android):

Concept Angular (Web) React Native (Mobile)
Build Output Static assets directory (dist/) Signed Native Binary (.ipa / .aab)
CI/CD Build System GitHub Actions / Cloudflare Pages EAS Build (cloud macOS & Linux builders)
App Updates Instant reload on web refresh App Store review cycle OR EAS Update (OTA)
Distribution Public URL Apple TestFlight / Google Play Console

2. Configuring `app.json` (The Mobile App Manifest)

The app.json file configures app icons, splash screens, bundle identifiers, and native permissions:

{
  "expo": {
    "name": "BeReal Clone",
    "slug": "berealclone",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "userInterfaceStyle": "dark",
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#000000"
    },
    "ios": {
      "supportsTablet": false,
      "bundleIdentifier": "com.yourname.berealclone",
      "infoPlist": {
        "NSCameraUsageDescription": "BeReal Clone needs camera access to take daily dual photos.",
        "NSPhotoLibraryUsageDescription": "BeReal Clone needs photo access to choose profile avatars."
      }
    },
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#000000"
      },
      "package": "com.yourname.berealclone",
      "permissions": [
        "CAMERA",
        "READ_EXTERNAL_STORAGE",
        "WRITE_EXTERNAL_STORAGE"
      ]
    },
    "plugins": [
      "expo-router",
      [
        "expo-camera",
        {
          "cameraPermission": "Allow BeReal Clone to access your camera."
        }
      ]
    ]
  }
}

3. The `eas.json` Multi-Environment Pipeline

Similar to Angular's angular.json configurations (development, staging, production), EAS uses eas.json:

{
  "cli": {
    "version": ">= 12.0.0"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "preview": {
      "distribution": "internal"
    },
    "production": {
      "autoIncrement": true
    }
  },
  "submit": {
    "production": {}
  }
}

4. Key EAS Commands for Engineers

  • eas login — Authenticate your CLI with your Expo cloud workspace.
  • eas build --profile development --platform ios — Build a custom dev client containing native modules.
  • eas build --profile preview --platform all — Generate internal test builds installable via QR code / link.
  • eas build --profile production --platform all — Create App Store & Google Play production binaries.
  • eas update --branch production --message "Fix auth redirect bug" — Deploy instant Over-The-Air bug fixes to users without going through App Store review.
