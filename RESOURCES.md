# React Native & Expo Resources

## Knowledge

- [Expo Official Documentation](https://docs.expo.dev/)
  The primary authority on Expo Router, managed workflow, native builds, and device APIs.
- [React Native Official Documentation](https://reactnative.dev/docs/getting-started)
  Core React Native primitive components (`View`, `Text`, `FlatList`, `Image`), flexbox layout engine, and platform APIs.
- [React Official Docs - Thinking in React](https://react.dev/learn/thinking-in-react)
  Essential mental model shift for state ownership, one-way data flow, and component lifecycle compared to Angular.
- [React Native Debugging Guide](https://reactnative.dev/docs/debugging)
  Official guide covering Chrome DevTools, React DevTools, inspect element, and error stack trace navigation.

## Wisdom (Communities)

- [r/reactnative Subreddit](https://reddit.com/r/reactnative)
  Active community discussing library choices, state management, performance optimization, and job market trends.
- [Expo Discord Community](https://chat.expo.dev)
  Real-time help from Expo core maintainers and mobile devs for build errors and API troubleshooting.
