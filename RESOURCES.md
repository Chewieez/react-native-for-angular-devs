# React Native & Expo Resources

## Knowledge

- [Expo Official Documentation](https://docs.expo.dev/)
  The primary authority on Expo Router, managed workflow, native builds, and device APIs.
- [React Native Official Documentation](https://reactnative.dev/docs/getting-started)
  Core React Native primitive components (`View`, `Text`, `FlatList`, `Image`), flexbox layout engine, and platform APIs.
- [React Official Docs - Thinking in React](https://react.dev/learn/thinking-in-react)
  Essential mental model shift for state ownership, one-way data flow, and component lifecycle compared to Angular.
- [React Native Debugging Guide](https://reactnative.dev/docs/debugging)
  Official guide covering Chrome DevTools, React DevTools, inspect element, and error stack trace navigation.

## Wisdom (Communities)

- [r/reactnative Subreddit](https://reddit.com/r/reactnative)
  Active community discussing library choices, state management, performance optimization, and job market trends.
- [Expo Discord Community](https://chat.expo.dev)
  Real-time help from Expo core maintainers and mobile devs for build errors and API troubleshooting.

## Essential NPM Packages (Used Across Lessons)

- [`react-native-safe-area-context`](https://www.npmjs.com/package/react-native-safe-area-context) — Handle notches, status bars, and home indicators.
- [`expo-router`](https://www.npmjs.com/package/expo-router) — File-based routing and universal deep linking.
- [`@tanstack/react-query`](https://www.npmjs.com/package/@tanstack/react-query) — Async state caching and optimistic mutations.
- [`@tanstack/query-sync-storage-persister`](https://www.npmjs.com/package/@tanstack/query-sync-storage-persister) — Synchronous disk cache persister adapter for TanStack Query.
- [`@supabase/supabase-js`](https://www.npmjs.com/package/@supabase/supabase-js) — Database and auth client.
- [`@react-native-async-storage/async-storage`](https://www.npmjs.com/package/@react-native-async-storage/async-storage) — Async key-value storage for mobile.
- [`react-native-mmkv`](https://www.npmjs.com/package/react-native-mmkv) — High-throughput synchronous key-value storage engine.
- [`react-native-url-polyfill`](https://www.npmjs.com/package/react-native-url-polyfill) — URL polyfill for React Native environments.
- [`expo-camera`](https://www.npmjs.com/package/expo-camera) — Native camera viewfinder and barcode scanner.
- [`expo-image-picker`](https://www.npmjs.com/package/expo-image-picker) — System photo gallery access and selection.
- [`expo-file-system`](https://www.npmjs.com/package/expo-file-system) — Local file system access and binary reads.
- [`base64-arraybuffer`](https://www.npmjs.com/package/base64-arraybuffer) — Base64 string to ArrayBuffer encoder/decoder.
- [`expo-haptics`](https://www.npmjs.com/package/expo-haptics) — Apple Taptic Engine and Android haptic feedback.
- [`eas-cli`](https://www.npmjs.com/package/eas-cli) — Expo Application Services cloud build & OTA update CLI.
- [`expo-notifications`](https://www.npmjs.com/package/expo-notifications) — APNs & FCM push notification handling.
- [`expo-device`](https://www.npmjs.com/package/expo-device) — Physical device detection and hardware information.
- [`react-native-reanimated`](https://www.npmjs.com/package/react-native-reanimated) — UI-thread Worklet animations and physics springs.
- [`react-native-gesture-handler`](https://www.npmjs.com/package/react-native-gesture-handler) — Declarative native gestures (pinch, pan, swipe).
- [`expo-secure-store`](https://www.npmjs.com/package/expo-secure-store) — Encrypted storage on iOS Keychain & Android KeyStore.
- [`expo-local-authentication`](https://www.npmjs.com/package/expo-local-authentication) — FaceID / TouchID / Fingerprint biometric authentication.
- [`@react-native-community/netinfo`](https://www.npmjs.com/package/@react-native-community/netinfo) — Real-time network status and reachability monitoring.
