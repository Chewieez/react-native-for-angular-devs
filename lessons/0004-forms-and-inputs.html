Lesson 0004: Forms & Controlled Inputs in React Native

Connecting UI inputs to state, handling mobile keyboards, and validating user data

1. Angular Forms vs. React Controlled Components

In Angular, form binding is handled via two-way directive binding ([(ngModel)]) or Reactive Forms (FormGroup / FormControl). React Native uses Controlled Components, where component state explicitly drives input value, and keystrokes fire callback updates.

Angular Pattern React Native Controlled Component Key Technical Difference
[(ngModel)]="email" value={email} onChangeText={setEmail} React splits binding into an explicit value prop and an onChangeText callback.
formControlName="email" Local useState hooks No built-in HTML form module. Component state directly controls the input string.
(ngSubmit)="onLogin()" <Pressable onPress={handleLogin}> No HTML <form> element on native mobile. Buttons handle tap events directly via onPress.
(input)="onInput($event)" onChangeText={(text) => ...} onChangeText passes the raw string parameter directly (no $event.target.value wrapping!).

2. Production Code Example: Login Form with Keyboard Handling

import React, { useState } from 'react';
import {
  View,
  Text,
  TextInput,
  Pressable,
  StyleSheet,
  KeyboardAvoidingView,
  Platform,
  TouchableWithoutFeedback,
  Keyboard,
  ActivityIndicator,
} from 'react-native';

export function LoginScreen() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [isLoading, setIsLoading] = useState(false);
  const [errorMessage, setErrorMessage] = useState('');

  const handleLogin = async () => {
    if (!email || !password) {
      setErrorMessage('Please fill in all fields.');
      return;
    }

    setErrorMessage('');
    setIsLoading(true);

    try {
      // Execute authentication
      await new Promise(resolve => setTimeout(resolve, 1000));
    } catch (err) {
      setErrorMessage('Authentication failed.');
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <KeyboardAvoidingView
      style={styles.flex}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}>
      <TouchableWithoutFeedback onPress={Keyboard.dismiss}>
        <View style={styles.container}>
          <Text style={styles.headerTitle}>Welcome Back</Text>

          {errorMessage ? <Text style={styles.errorText}>{errorMessage}</Text> : null}

          <Text style={styles.label}>Email Address</Text>
          <TextInput
            style={styles.input}
            value={email}
            onChangeText={setEmail}
            placeholder="name@example.com"
            placeholderTextColor="#888888"
            keyboardType="email-address"
            autoCapitalize="none"
            autoCorrect={false}
            returnKeyType="next"
          />

          <Text style={styles.label}>Password</Text>
          <TextInput
            style={styles.input}
            value={password}
            onChangeText={setPassword}
            placeholder="Enter password..."
            placeholderTextColor="#888888"
            secureTextEntry
            autoCapitalize="none"
            returnKeyType="done"
            onSubmitEditing={handleLogin}
          />

          <Pressable
            style={[styles.button, isLoading && styles.buttonDisabled]}
            onPress={handleLogin}
            disabled={isLoading}>
            {isLoading ? (
              <ActivityIndicator color="#ffffff" />
            ) : (
              <Text style={styles.buttonText}>Sign In</Text>
            )}
          </Pressable>
        </View>
      </TouchableWithoutFeedback>
    </KeyboardAvoidingView>
  );
}

const styles = StyleSheet.create({
  flex: { flex: 1 },
  container: {
    flex: 1,
    justifyContent: 'center',
    paddingHorizontal: 24,
    backgroundColor: '#ffffff',
  },
  headerTitle: {
    fontSize: 28,
    fontWeight: 'bold',
    marginBottom: 24,
    color: '#111111',
  },
  label: { fontSize: 14, fontWeight: '600', marginBottom: 6, color: '#333333' },
  input: {
    height: 48,
    borderWidth: 1,
    borderColor: '#cccccc',
    borderRadius: 8,
    paddingHorizontal: 14,
    fontSize: 16,
    marginBottom: 16,
    backgroundColor: '#fafafa',
  },
  button: {
    height: 48,
    backgroundColor: '#007AFF',
    borderRadius: 8,
    justifyContent: 'center',
    alignItems: 'center',
    marginTop: 8,
  },
  buttonDisabled: { backgroundColor: '#a0c8f0' },
  buttonText: { color: '#ffffff', fontSize: 16, fontWeight: 'bold' },
  errorText: { color: '#d9381e', marginBottom: 12, fontWeight: '600' },
});

3. TextInput Props Quick Reference

  • onChangeText={(text) => ...}: Callback invoked on every character change with raw string value.
  • secureTextEntry={true}: Masks input for passwords.
  • autoCapitalize="none": Disables automatic initial letter capitalization on iOS (essential for email & username inputs!).
  • keyboardType="email-address": Displays mobile email keyboard layout featuring @ and .com keys.
  • returnKeyType="next" / "done": Controls mobile keyboard submit button label ("Next", "Done", "Search").
  • onSubmitEditing={handleAction}: Fires when the user taps the soft keyboard submit button.

4. Mobile Keyboard UX Best Practices

  • KeyboardAvoidingView: Automatically shifts UI components upward when the soft keyboard appears so inputs are not hidden behind the keyboard.
  • TouchableWithoutFeedback + Keyboard.dismiss: Tapping anywhere outside an active text input dismisses the soft keyboard.
