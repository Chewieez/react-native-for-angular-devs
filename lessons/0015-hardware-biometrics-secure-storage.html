🛡️ Pillar 5: Device Hardware, Animations & Production

Lesson 0015: Hardware Biometrics & Encrypted Storage

Translating WebAuthn and HTTP-only cookies to iOS Keychain / Android KeyStore (expo-secure-store) and FaceID (expo-local-authentication)

1. Web Security vs. Native Hardware Enclaves

In Angular web applications, tokens are often placed in localStorage or httpOnly cookies. On mobile devices, sensitive secrets (refresh tokens, encryption keys, biometric credentials) belong in hardware-backed secure storage:

Concept Angular (Web) React Native (Mobile)
Storage Target localStorage / sessionStorage iOS Keychain & Android KeyStore (Hardware Enclave)
Encryption Unencrypted plain-text files on disk AES-256 GCM encrypted with device master keys
Biometric Unlocking WebAuthn (browser-dependent) FaceID / TouchID / Fingerprint via expo-local-authentication
Persistence Across Reinstalls Cleared on site data reset iOS Keychain persists across app uninstall/reinstall (optional)

2. Encrypted Token Storage with expo-secure-store

Store private API keys and user refresh tokens securely:

// src/utils/secureStorage.ts
import * as SecureStore from 'expo-secure-store';
import { Platform } from 'react-native';

const REFRESH_TOKEN_KEY = 'user_refresh_token';

export async function saveSecureToken(token: string): Promise<void> {
  if (Platform.OS === 'web') {
    // Fallback for web preview
    sessionStorage.setItem(REFRESH_TOKEN_KEY, token);
    return;
  }

  await SecureStore.setItemAsync(REFRESH_TOKEN_KEY, token, {
    keychainAccessible: SecureStore.AFTER_FIRST_UNLOCK, // iOS: Accessible after first unlock
  });
}

export async function getSecureToken(): Promise<string | null> {
  if (Platform.OS === 'web') {
    return sessionStorage.getItem(REFRESH_TOKEN_KEY);
  }

  return await SecureStore.getItemAsync(REFRESH_TOKEN_KEY);
}

export async function deleteSecureToken(): Promise<void> {
  if (Platform.OS === 'web') {
    sessionStorage.removeItem(REFRESH_TOKEN_KEY);
    return;
  }

  await SecureStore.deleteItemAsync(REFRESH_TOKEN_KEY);
}

3. FaceID & Biometric Authentication (expo-local-authentication)

Prompt the user for biometric verification before unlocking private screens or performing sensitive actions:

// src/utils/biometrics.ts
import * as LocalAuthentication from 'expo-local-authentication';

export async function authenticateWithBiometrics(promptMessage = 'Unlock BeReal Account'): Promise<boolean> {
  // 1. Check if hardware supports biometrics (FaceID / Fingerprint)
  const hasHardware = await LocalAuthentication.hasHardwareAsync();
  if (!hasHardware) return false;

  // 2. Verify if user has enrolled fingerprints/FaceID on their device
  const isEnrolled = await LocalAuthentication.isEnrolledAsync();
  if (!isEnrolled) return false;

  // 3. Trigger native OS biometric prompt
  const result = await LocalAuthentication.authenticateAsync({
    promptMessage,
    fallbackLabel: 'Use Device Passcode',
    disableDeviceFallback: false,
  });

  return result.success;
}

4. Key Insights for Angular Leads

  • Never Store JWTs in AsyncStorage in Production: Always store sensitive session refresh tokens in SecureStore to protect against physical device extraction or jailbreak exploits.
  • 2KB Storage Limit: expo-secure-store is optimized for small secrets (keys, passwords, tokens). For large encrypted data sets, use an encrypted SQLite database.
  • Graceful Fallbacks: Always check hasHardwareAsync() and provide a PIN/passcode fallback so users without biometrics can still access your app.
