Lesson 0009: Async Data Fetching & Loading States

Translating Angular HttpClient & RxJS Observables to React Native async/await, Custom Hooks, and Native ActivityIndicator

1. Angular HttpClient / RxJS vs. React Native async/await & Hooks

In Angular, HTTP requests are handled by HttpClient returning cold RxJS Observable instances, often unwrapped in templates using the async pipe (items$ | async). In React Native, data fetching relies on standard fetch() or axios wrapped inside a custom hook or useEffect() with local state flags (data, loading, error):

Angular Pattern (RxJS) React Native Pattern (Hooks) Conceptual Difference
this.http.get<Post[]>(url) const res = await fetch(url); await res.json(); RxJS Observables streams vs. Promise-based async/await.
<div *ngIf="loading$ | async"> {loading && <ActivityIndicator />} Template async pipe vs. JavaScript conditional JSX short-circuiting.
catchError(err => of(fallback)) try { ... } catch (err) { setError(err.message); } RxJS operator error pipe vs. standard JavaScript try/catch blocks.
shareReplay(1) / Signals Custom Hook (e.g. useFeedData()) or TanStack Query Manual RxJS caching vs. React state encapsulation or query cache hooks.

2. Native Loading Indicators (ActivityIndicator)

Unlike web development where spinners are custom CSS keyframe animations, React Native provides a platform-native loading indicator component: ActivityIndicator. It renders as an iOS activity indicator on Apple devices and a Material Design circular progress indicator on Android:

import { View, Text, ActivityIndicator, StyleSheet } from 'react-native';

export default function LoadingExample({ isLoading, data }: { isLoading: boolean; data: string[] }) {
  if (isLoading) {
    return (
      <View style={styles.centerContainer}>
        <ActivityIndicator size="large" color="#007AFF" />
        <Text style={styles.loadingText}>Fetching feed...</Text>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      {/* Render fetched list */}
    </View>
  );
}

const styles = StyleSheet.create({
  centerContainer: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  loadingText: { marginTop: 12, fontSize: 14, color: '#666' },
  container: { flex: 1, padding: 16 }
});

3. Building a Custom Data Fetching Hook (The "Angular Service" Pattern)

In Angular, data fetching logic belongs inside a service class (e.g. FeedService). In React, the best practice is to encapsulate stateful fetching logic inside a custom hook (e.g. useFeed()):

// src/hooks/useFeedData.ts
import { useState, useEffect, useCallback } from 'react';

export interface Post {
  id: string;
  caption: string;
  imageUrl: string;
}

export function useFeedData() {
  const [posts, setPosts] = useState<Post[]>([]);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);

  const fetchFeed = useCallback(async () => {
    try {
      setLoading(true);
      setError(null);
      const response = await fetch('https://api.example.com/posts');
      if (!response.ok) throw new Error('Failed to load posts');
      const data = await response.json();
      setPosts(data);
    } catch (err: any) {
      setError(err.message || 'An unknown error occurred');
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => {
    fetchFeed();
  }, [fetchFeed]);

  return { posts, loading, error, refetch: fetchFeed };
}

4. Consuming the Custom Hook in a Component

Consuming the custom hook inside an Expo Router screen component gives you clean separation of concerns, complete with pull-to-refresh and error fallbacks:

// src/app/(tabs)/index.tsx
import { View, Text, FlatList, ActivityIndicator, StyleSheet, RefreshControl } from 'react-native';
import { useFeedData } from '../../hooks/useFeedData';

export default function FeedScreen() {
  const { posts, loading, error, refetch } = useFeedData();

  if (loading && posts.length === 0) {
    return (
      <View style={styles.centered}>
        <ActivityIndicator size="large" color="#007AFF" />
      </View>
    );
  }

  if (error) {
    return (
      <View style={styles.centered}>
        <Text style={styles.errorText}>Error: {error}</Text>
      </View>
    );
  }

  return (
    <FlatList
      data={posts}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <View style={styles.card}>
          <Text style={styles.caption}>{item.caption}</Text>
        </View>
      )}
      refreshControl={
        <RefreshControl refreshing={loading} onRefresh={refetch} colors={['#007AFF']} />
      }
    />
  );
}

const styles = StyleSheet.create({
  centered: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  errorText: { color: '#FF3B30', fontSize: 16, fontWeight: '600' },
  card: { padding: 16, borderBottomWidth: 1, borderColor: '#eee' },
  caption: { fontSize: 16 }
});

5. Key Insights for Angular Engineers

  • No RxJS Subscriptions to Unsubscribe: React hooks clean up automatically when components unmount if cleanup functions are returned from useEffect.
  • Declarative Pull-to-Refresh: React Native's RefreshControl plugs directly into FlatList or ScrollView with simple refreshing and onRefresh props.
  • Production Apps: For complex caching, background revalidation, and optimistic updates, use TanStack React Query (the React ecosystem equivalent to RxJS state stores).
