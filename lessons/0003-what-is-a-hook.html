Lesson 0003: What is a React Hook?

Demystifying hooks, state, lifecycle synchronization, and custom hook abstractions for Angular developers

1. What Exactly is a React Hook?

A Hook is a plain JavaScript function (always prefixed with use, such as useState or useEffect) that lets functional components attach to React engine capabilities like state memory, lifecycle synchronization, context subscription, and memoization.

Concept Angular (Web) React Native (Mobile)
Local Component State Class property (this.count = 0) / Signals const [count, setCount] = useState(0) (Batched updates)
Lifecycle & Side Effects ngOnInit + ngOnDestroy useEffect(() => { ... return () => cleanup; }, [])
Service / Context Access constructor(private svc: Svc) / inject() useContext(MyContext) (Reads nearest Provider value)
Mutable Instance Ref @ViewChild('myInput') / ElementRef useRef(initialValue) (Persistent mutable ref without re-renders)
Memoized Computation computed(() => expensive()) / Pure Pipe useMemo(() => compute(), [deps]) (Caches expensive values)
Memoized Function Callback Class method reference useCallback(() => {}, [deps]) (Preserves function identity)

2. Side-by-Side Lifecycle Comparison: Subscribing to Data

Angular Component (`ngOnInit` & `ngOnDestroy`)

export class DataFeedComponent implements OnInit, OnDestroy {
  private subscription!: Subscription;
  data: DataItem[] = [];

  ngOnInit() {
    this.subscription = this.dataService.streamData().subscribe(items => {
      this.data = items;
    });
  }

  ngOnDestroy() {
    if (this.subscription) {
      this.subscription.unsubscribe(); // Manual cleanup required
    }
  }
}

React Component (`useEffect` with Cleanup Return)

import { useState, useEffect } from 'react';
import { View, Text } from 'react-native';

export function DataFeedScreen() {
  const [data, setData] = useState<DataItem[]>([]);

  useEffect(() => {
    // 1. Setup Phase (Runs after mount)
    const subscription = dataService.streamData((items) => {
      setData(items);
    });

    // 2. Cleanup Return Function (Runs before unmount)
    return () => {
      subscription.unsubscribe();
    };
  }, []); // [] runs setup once on mount & cleanup on unmount

  return (
    <View>
      <Text>Items count: {data.length}</Text>
    </View>
  );
}

3. The 3 Golden Rules of Hooks

  1. Only Call Hooks at the Top Level: Never call hooks inside loops, conditional statements (if), or nested functions. React relies on the execution order of hooks across re-renders to maintain state associations.
  2. Only Call Hooks from React Functions: Call hooks only from React functional components or custom hooks. Do not call them from standard JS helper utilities.
  3. Strict Naming Convention: Custom hook names MUST start with use (e.g. useAuth, useDebounce, useFetch). This allows React linters to validate hook dependencies automatically.
  4. Cleanup vs. Angular `takeUntilDestroyed()`: Instead of managing separate `ngOnDestroy` lifecycle hooks or `takeUntilDestroyed()` RxJS operators, React unifies setup and teardown into a single function closure via return () => cleanup().

4. Creating Production Custom Hooks

Custom hooks let you extract reusable component logic into modular functions. Here is a custom useDebounce hook:

import { useState, useEffect } from 'react';

export function useDebounce(value: T, delayMs: number = 300): T {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delayMs);

    return () => {
      clearTimeout(timer); // Cancel previous timer on value change
    };
  }, [value, delayMs]);

  return debouncedValue;
}
